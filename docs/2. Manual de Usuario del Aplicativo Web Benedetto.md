Manual de Usuario del Aplicativo Web de Gestión Empresarial ModaClick

# 1. Introducción

Este manual de usuario tiene como objetivo guiar a los usuarios en el uso del Aplicativo
Web de Gestión Empresarial ModaClick. A través de este documento, los usuarios
aprenderán a navegar por la plataforma, gestionar clientes, empleados, productos y
ventas, y utilizar las distintas funcionalidades disponibles.

# 2. Instalación y Configuración

Antes de utilizar la aplicación, es necesario instalar y configurar el entorno de
desarrollo.

## 2.1 Requisitos Previos

- Python 3.10 o superior
- Flask
- MySQL Server
- MySQL Workbench
- Bootstrap 5.
- Navegador web compatible: Google Chrome, Mozilla Firefox, Microsoft Edge
    o Safari.

## 2.2 Instalación del Proyecto

1. Clonar el repositorio
2. git clone https://github.com/usuario/modaclick.git
3. cd modaclick
4. Crear y activar un entorno virtual
5. python -m venv venv
6. source venv/bin/activate # En Windows: venv\Scripts\activate
7. Instalar dependencias
8. pip install -r requirements.txt
9. Configurar la base de datos
    o Crear una base de datos en MySQL con el nombre modaclick_db.
    o Importar el archivo database.sql incluido en el proyecto.
10. Ejecutar la aplicación
11. flask run
12. Acceder a la aplicación
    o Abra su navegador y vaya a [http://127.0.0.1:5000.](http://127.0.0.1:5000.)

# 3. Requisitos del Sistema

Antes de comenzar a utilizar la aplicación, asegúrese de cumplir con los siguientes
requisitos:

- Navegador web: Google Chrome, Mozilla Firefox, Microsoft Edge o Safari.
- Conexión a Internet estable.


- Cuenta de usuario: Un administrador debe proporcionarle un usuario y
    contraseña para acceder.

# 4. Acceso al Sistema

## 4.1 Inicio de Sesión

1. Abra su navegador web y acceda a la URL de la aplicación.
2. Ingrese su nombre de usuario y contraseña en los campos correspondientes.
3. Haga clic en el botón "Iniciar sesión".
4. Si sus credenciales son correctas, será redirigido al panel principal.

## 4.2 Recuperar Contraseña

1. En la pantalla de inicio de sesión, haga clic en "¿Olvidó su contraseña?".
2. Ingrese su correo electrónico y haga clic en "Enviar".
3. Siga las instrucciones enviadas a su correo para restablecer la contraseña.

# 5. Navegación en la Aplicación

Al ingresar al sistema, encontrará un menú principal con las siguientes opciones:

- Dashboard: Resumen de la actividad de la empresa.
- Gestíon de Clientes: Registro, edición y eliminación de clientes.
- Gestíon de Empleados: Administración del personal de la empresa.
- Productos: Creación, actualización y control del inventario de productos.
- Ventas y Pedidos: Registro y seguimiento de pedidos realizados.
- Reportes: Visualización y descarga de informes de gestión.
- Configuración: Opciones para modificar información personal y ajustes de
    seguridad.

# 6. Uso de Funcionalidades

## 6.1 Agregar un Cliente

1. Diríjase a la sección "Gestíon de Clientes".
2. Haga clic en el botón "Agregar Cliente".
3. Complete los campos requeridos (nombre, dirección, contacto, etc.).
4. Presione "Guardar" para registrar el nuevo cliente.

## 6.2 Registrar un Producto

1. Acceda a la sección "Productos".
2. Haga clic en "Nuevo Producto".
3. Ingrese el nombre, descripción, precio y cantidad disponible.
4. Presione "Guardar".

## 6.3 Realizar una Venta


1. Vaya a "Ventas y Pedidos".
2. Haga clic en "Nueva Venta".
3. Seleccione el cliente y los productos vendidos.
4. Indique la cantidad y forma de pago.
5. Confirme la venta y genere el comprobante.

# 7. Cierre de Sesión

1. Haga clic en su nombre de usuario en la esquina superior derecha.
2. Seleccione la opción "Cerrar sesión".
3. Será redirigido a la pantalla de inicio de sesión.

# 8. Preguntas Frecuentes

¿Qué hago si no puedo iniciar sesión?

- Verifique que su usuario y contraseña sean correctos.
- Restablezca su contraseña siguiendo los pasos de la sección 4.2.

¿Cómo puedo cambiar mi contraseña?

1. Ingrese a "Configuración" en el menú.
2. Seleccione "Cambiar contraseña".
3. Ingrese su contraseña actual y la nueva.
4. Guarde los cambios.

¿Cómo descargo reportes?

1. Acceda a la sección "Reportes".
2. Seleccione el tipo de informe.
3. Haga clic en "Generar Reporte".
4. Descargue el archivo generado.
